================================================================================
  MODELS  (farmersmarket/models.py)
================================================================================

  Farmer        OneToOne → User; name, contact, address
  Farm          FK → Farmer; name, location
  Client        OneToOne → User; name, contact, address, gender, account_status

  Product
    crop_name, category (choices), unit (choices, default kg)
    quantity_available, price, currency (default UGX)
    harvest_date (DateField, optional — drives freshness badge)
    farmer FK, description, image, is_available
    created_at, updated_at
    @property freshness_label → ('green'|'yellow'|'red', label_text)
    @property avg_rating      → float or None
    @property rating_count    → int

  ProductRating   FK → Product + Client; stars(1–5), review, created_at
                  unique_together = (product, client)

  Order
    client FK, status (6 states), delivery_type, total_amount
    delivery_address, notes, order_date
    STATUS choices: Pending → Confirmed → Preparing → Ready → Delivered | Cancelled

  OrderItem     FK → Order + Product; quantity, price_at_purchase
  Payment       FK → Order; amount, payment_method, is_successful
  Notification  FK → Farmer|Client; type, message, is_read, related_order

================================================================================
  VIEWS  (farmersmarket/views.py)
================================================================================

  home()                    Latest 8 products
  login_view()              Authenticate → dashboard
  register_view()           Creates Farmer or Client profile
  logout_view()             Clears cart session + logs out
  dashboard_view()          Auto-routes: farmer_dashboard or client_dashboard
                            Farmer gets: today_count, today_revenue, low_stock
  marketplace_view()        Filter by q/category/farmer/min_price/max_price
  product_detail_view()     Single product + ratings list
  rate_product()            POST — update_or_create ProductRating
  cart_view()               Session cart grouped by farmer
  add_to_cart()             POST — validates stock before adding
  remove_from_cart()        POST
  update_cart()             POST — removes if qty=0
  checkout_view()           GET: show; POST: create Order+Items, deduct stock,
                            creates Mock Payment (always successful),
                            notify farmers, clear cart
  order_detail_view()       Order summary + progress tracker
  update_order_status()     POST (farmer): Pending→Confirmed→Preparing→Ready→Delivered
  farmer_earnings_view()    Revenue by period + best sellers + recent orders
  mark_notifications_read() POST — marks all unread for current user

  _simple_form_view()       Shared stub for admin CRUD views

================================================================================
  ORDER STATE MACHINE
================================================================================

  VALID_TRANSITIONS = {
      'Pending':   ['Confirmed', 'Cancelled'],
      'Confirmed': ['Preparing', 'Cancelled'],
      'Preparing': ['Ready'],
      'Ready':     ['Delivered'],
  }

================================================================================
  CURRENCY
================================================================================

  Per-product field on Product.currency (CharField, default='UGX').
  Choices: UGX, KES, TZS, USD, EUR, GBP.
  Shown consistently as "UGX 2,500 / kg" across all pages.

================================================================================
  MOCK PAYMENT
================================================================================

  Checkout creates a Payment record automatically with a random transaction ID.
  Status is always "is_successful=True".
